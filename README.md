# Micromatch Tester Online

A simple browser tool for testing glob patterns against arbitrary inputs – powered by [micromatch](https://github.com/micromatch/micromatch).

## Usage

- **Start the dev server**: `npm run dev`, then open [http://localhost:5173](http://localhost:5173) in your browser.
- **Create a production build** `npm run build` – output goes to the `dist/` folder.
- **Run tests:** `npm test`
- **Format code:** `npm run format`
